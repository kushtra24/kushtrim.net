# kushtrim

Personal portfolio and showroom of how I work and build projects. Mobile first, responsive, light and dark mode, English and German.

Content: home page with featured projects, journey, profile and skills, plus project, CV and contact pages.

## Stack

Vue 3 · TypeScript · Vite · vue-router · Tailwind CSS v4 · Material Symbols · ESLint (+ Stylistic for formatting). Hosted on Netlify.

## Quick start

```sh
npm install
npm run dev
```

Open <http://localhost:5173>.

## Scripts

```sh
npm run dev       # frontend dev server
npm run build     # type-check + production build
npm run preview   # serve the production build
npm run lint      # check code quality and formatting
npm run format    # auto-fix lint and formatting issues
```
